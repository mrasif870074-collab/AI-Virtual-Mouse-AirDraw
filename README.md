# AI Virtual Mouse & AirDraw

A Hand Gesture Based Virtual Mouse and Air Drawing System built using Python and Computer Vision.

## Features

- Hand Gesture Based Cursor Movement
- Left Click and Right Click
- Double Click
- Drag and Drop
- Scroll Control
- Air Drawing
- Multiple Drawing Colors
- Eraser
- Clear Drawing

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- PyAutoGUI
- Pynput

## Installation

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the project:

   python main.py
